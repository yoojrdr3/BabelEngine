# 바벨 엔진 — 분대 조작 · 카메라 프로토타입

외부 의존성이 없는 HTML/Canvas 프로토타입입니다. 빌드 과정이 필요 없습니다.

## 실행 방법

`index.html`을 브라우저에서 바로 열면 됩니다. Chrome, Edge, Firefox에서 동작합니다.

로컬 서버로 띄우려면 이 폴더에서 아래 명령을 실행한 뒤 http://localhost:8000 에 접속하세요.

```
python -m http.server 8000
```

## 조작법

**아바타 모드** (파랑 분대가 선택되지 않은 상태)

| 입력 | 동작 |
|---|---|
| W A S D | 빨강 분대 이동 |
| 마우스 | 빨강 분대 조준 |
| 좌클릭 | 커서 방향으로 1발 발사 |
| 1–4 | 해당 파랑 분대 선택 → 분대 지휘 모드 |
| 우클릭 | 모든 분대가 클릭 위치에 집결(2×2로 촘촘하게, 분대장 간격 140u). 모두 도착하면 그 무리가 커서를 따라 이동. 각 분대는 D 제한을 지킴 |
| (참고) | 우클릭 첫 입력의 집결·따라가기는 **전투 행동 없이** 진행 (사격·근접 돌격 안 함, "집결 중 / 커서 추적 (비전투)" 표시) |
| 따라가는 중 우클릭 한 번 더 | 전투를 기존대로 허용하며 따라가기 ("커서 추적" 표시) |
| 우클릭 더블 클릭 (또는 Esc, 분대 선택) | 모든 분대 따라가기 중지, 그 자리에 고정. 좌클릭은 공격 전용이라 따라가기에 영향 없음 |

**분대 지휘 모드** (파랑 분대가 선택된 상태)

| 입력 | 동작 |
|---|---|
| W A S D | 빨강 분대 이동 (직접 조작은 항상 아바타에 유지) |
| 우클릭 | 선택 분대를 그 지점으로 이동. 위치는 빨강 분대 기준 상대 위치로 저장되며, D보다 멀면 같은 방향의 최대 거리 지점으로 제한 |
| 좌클릭 | 선택 분대가 현재 위치에서 커서 방향으로 스킬 1발 발사 (방향 지정 단발, 빗나갈 수 있음) |
| 1–4 | 선택 분대 전환 |
| 같은 숫자 한 번 더 | 카메라를 선택 분대 쪽으로 이동: 빨강→분대장 선의 75% 지점 (튜닝 가능) |
| 우클릭 (1번째) | 선택 분대가 커서를 따라 이동 시작 (지정 위치가 매 프레임 커서로 갱신, D 제한은 그대로) |
| (참고) | 우클릭 첫 입력의 따라가기는 **전투 행동 없이** 진행 ("커서 추적 (비전투)" 표시) |
| 우클릭 (2번째) | 전투를 기존대로 허용하며 따라가기 ("커서 추적" 표시) |
| 우클릭 더블 클릭 | 따라가기 해제, 그 순간의 커서 위치에 고정. 다른 분대 선택·Space·Esc로도 해제. 좌클릭은 공격 전용이라 따라가기에 영향 없음 |
| Space | 첫 번째: 아바타 선택만 (카메라는 그대로) · 두 번째: 카메라도 아바타로 복귀 |
| Esc | 선택 해제 → 아바타 모드 |

`마우스 휠`: 현재 모드의 카메라 줌 조절 (0.3×~2.0×, 화면 중앙 기준)
`H`: 도움말 패널 보이기/숨기기
`X`: 전투 행동 금지 — 모든 분대(아바타 분대원 포함)의 자동 사격·근접 돌격을 멈추고, 근접 중이던 분대는 지정 위치로 복귀. 카메라 포인트에 50u 크기의 붉은 X 표시. 좌클릭 공격(아바타 사격·분대 스킬)은 그대로 가능
`X` 더블 입력(0.3초 안): 전투 행동 금지 해제

## 원거리 사거리

모든 원거리 공격(빨강 사격, 분대 스킬, 분대 자동 사격)은 같은 사거리를 씁니다. 사거리는 **검은 원의 지름(D)**이며, 투사체는 쏜 위치에서 정확히 이 거리까지만 날아갑니다. D를 바꾸면 사거리도 함께 바뀌고, 우측 패널의 배율 슬라이더로 따로 조절할 수도 있습니다.

## 파랑 분대 자동 전투

각 파랑 분대는 독립적으로 판단합니다. 분대 아래와 카드에 현재 상태가 표시됩니다.

| 상태 | 조건 | 행동 |
|---|---|---|
| 대기 / 사격 | 기본 | 지정 위치를 유지하고, 사거리 안의 가장 가까운 적을 자동 사격 (0.9초 간격) |
| 근접 전투 | 자기 검은 원 안에 적이 들어옴 | 그 적에게 붙어서 근접 공격 (0.55초 간격, 사격보다 강함) |
| 퇴각 | 근접 중 적이 검은 원 밖으로 벗어남 (빨강 분대가 멀어지거나 적이 이동) | 아바타 쪽으로 물러남 |
| 복귀 | 퇴각 완료, 또는 근접 대상 처치 | 원래 지정 위치로 돌아감. 퇴각 후에는 위치 도착 1초 뒤부터 다시 근접 돌격 |

- 근접 대상을 처치하면 검은 원 안에 다른 적이 있을 때 바로 그 적에게 붙고, 없으면 복귀합니다.
- 우클릭 이동 명령은 자동 전투보다 우선합니다. 명령을 받은 분대는 근접 전투를 멈추고 새 위치로 가며, 도착하기 전까지는 근접 돌격을 하지 않습니다(사격은 함).
- 어떤 상태에서도 빨강 분대와의 거리는 D를 넘지 않습니다.

## 분대원

모든 분대(빨강 포함)는 분대장 1명과 분대원 4명으로 구성됩니다. 분대원 크기는 분대장의 70%입니다.

- **이동**: 분대장의 이동 방향을 기준으로 V자 대형(양 날개 2명 + 후미 2명)을 유지하며 따라갑니다. 평시 간격은 기본값의 3배(분대장에서 약 126~148)이며, 튜닝 패널의 "분대원 평시 간격"으로 조절할 수 있습니다. 서로, 분대장, 적과 겹치지 않습니다.
- **원거리**: 분대가 대기·복귀 상태일 때 분대의 사격 대상을 각자 자기 위치에서 자동 사격합니다(약 1.3초 간격). 빨강 분대원도 아바타 사거리 안의 적을 자동 사격합니다.
- **근접**: 분대가 근접 전투에 들어가면 분대장과 함께 적을 둘러싸고(5방향) 각자 공격합니다.
- **퇴각·복귀**: 공격하지 않고 대형을 유지하며 분대장을 따라갑니다.
- 좌클릭 사격·스킬은 여전히 분대장(아바타) 1발입니다. 거리 제한 D, 카메라, 검은 원은 모두 분대장 위치를 기준으로 계산합니다.
- 분대원이 늘어난 만큼 적 체력을 30으로 올렸습니다.

## 화면 표시

- **분대 방향 화살표**: 항상 표시되며, 카메라 목표(초록 점 — 아바타 모드에서는 아바타, 카메라가 분대로 가 있으면 75% 지점) 둘레에 1~4번 화살표가 각 분대장 방향을 가리킵니다. 선택한 분대의 화살표는 초록 테두리로 진하게 표시됩니다. 분대가 화면 안에 있으면 흐리게, 화면 밖이면 진하게 보입니다. 분대가 공격 중(사격·근접 공격)이면 화살표가 2초에 한 번 앞뒤로 짧게 튀고(분대마다 시점이 엇갈림), 방향이 비슷한 화살표는 겹치지 않게 원 위에서 벌어지며(머리는 실제 분대장 방향), 피격 중이면 빨강·흰색으로 점멸합니다. 아직 적이 공격하지 않으므로 피격 점멸은 튜닝 패널의 "분대 피격 테스트" 버튼으로 확인할 수 있습니다.

- **초록 점**: 카메라 목표. 아바타 모드에서는 빨강 분대, 카메라가 분대로 가 있으면 빨강 분대에서 그 분대장까지의 선 위 75% 지점(분대 쪽)입니다.
- **+ (화면 중앙)**: 실제 카메라 중심. 초록 점을 향해 부드럽게 따라갑니다.
- **검은 원**: 거리 제한입니다. 지름이 D이고, 빨강 분대에서 해당 파랑 분대 방향으로 뻗어 있습니다. 선택된 분대의 원은 진하게, 나머지는 흐리게 표시됩니다.
- **파랑 점선 원 (작은 원)**: 분대에 지정된 상대 위치입니다. 빨강 분대를 따라 함께 움직입니다.
- **점선 큰 원**: 원거리 사거리입니다. 지금 좌클릭으로 쏘는 쪽(아바타 모드는 빨강, 지휘 모드는 선택 분대)은 진하게, 나머지 분대는 흐리게 표시됩니다.
- **우측 패널**: D(기본 1440), 사거리 배율, 카메라 줌, 카메라 추적 속도, 분대 가속·감속(반응성, 기본 3), 분대 최대 이동 속도(기본 480)를 실시간으로 조절할 수 있습니다. 두 분대 값은 분대가 혼자 움직일 때(이동 명령·돌격·퇴각·복귀)에만 적용되고, 아바타를 따라가는 움직임에는 영향이 없습니다. 

## 카메라 줌

- 모드마다 줌이 따로 있습니다: **아바타 모드 1.75×**, **분대 지휘 모드 1.0×** (기본값).
- 숫자 키를 한 번 누르면 분대만 선택되고 카메라·줌은 아바타에 그대로입니다(1.75×). 같은 숫자를 한 번 더 누르면 카메라가 그 분대 쪽 75% 지점으로 가며, 그 분대가 아바타로부터 제한 원 반지름(D/2) 안이면 1.0×, 밖이면 0.6×로(분대가 움직여 경계를 넘으면 자동 전환, 경계 ±20u 여유), Space/Esc로 아바타 모드에 돌아가면 1.75×로 부드럽게 바뀝니다. 다른 숫자로 분대를 바꾸면 선택만 바뀌고 카메라·줌은 그대로(이전 분대 쪽 카메라 포인트, 또는 아바타)이며, 그 숫자를 한 번 더 누르거나 Space/Esc를 누를 때 움직입니다.
- 마우스 휠은 **현재 모드의 줌**을 조절하고, 그 값은 기억됩니다. 예: 분대 지휘 모드에서 휠로 0.8×로 바꾸면 다음에 분대를 선택할 때도 0.8×가 됩니다.
- 튜닝 패널의 "아바타 모드 줌", "분대 카메라 줌 (반지름 안/밖)" 슬라이더는 휠 값과 연동되며, 직접 바꿀 수도 있습니다. 확대·축소는 화면 중앙(카메라 목표) 기준입니다.
